# Interactive Data Visualization Web (`interactive-data-visualization-web`)

Browser-based interactive visualizations for complex graphs, timelines, game lore, and single-file reactive widgets.

## Frameworks & Generators
- **Network Graphs:** Zero-build D3.js force-directed graphs with zoom, pan, and node inspection.
- **Timelines:** Chronological Vis.js timeline bands for release schedules and historical lore.
- **Micro-Apps:** Self-contained single-file HTML/JS calculators and parameter tuners with zero npm build step.
- **Generator Scripts:**
  `python3 ~/.gemini/config/skills/interactive-data-visualization-web/scripts/data_vis_generator.py`
  `python3 ~/.gemini/config/skills/interactive-data-visualization-web/scripts/lore_research_compiler.py`

## Related & Interoperating Skills
- **`modern-web-architecture`**: Modern Jamstack and SSG development with Astro, VitePress, Content Collections, and GitHub Pages CI/CD.
- **`console-game-decompilation`**: Matching binary decompilation for console ROMs and retro binaries using Splat, m2c, and objdiff.
- **`human-crafted-web-design`**: Anti-AI web design heuristics, Linear/Stripe aesthetics, typography hierarchy, and production Tailwind.
